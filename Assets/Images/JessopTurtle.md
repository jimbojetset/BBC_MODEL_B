# Jessop turtle sprite

`JessopTurtle.png` is an AI-generated top-view illustration for the emulator, based on the historic Jessop Ralph's clear dome, motors, wheels, wiring and electronics. It is an illustrative reconstruction, not a photograph or an exact component-layout diagram.

Reference: Museums Victoria, object HT 62396, circa 1984 Jessop turtle, including the top-view image and recorded 300 mm outside diameter.
https://collections.museumsvictoria.com.au/items/2620712

Reference image credit: Museums Victoria, CC BY 4.0.
https://creativecommons.org/licenses/by/4.0/

The reconstruction changes the orientation, component arrangement and lighting. The white-background sprite is drawn opaquely within a circular clip so the turtle covers the ink beneath its body; it does not contain an alpha channel.
